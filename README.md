# curly-meme

Plugin-Marketplace mit dem Plugin **schweizer-rechtsassistent**.

## Inhalt
- `skills/dsg-pruefung`: Prüfung von Klauseln nach DSG (SR 235.1) mit Bezügen zu StGB und ZGB
- `commands/dsg-check`: Befehl `/dsg-check <Klausel|Datei>`

## Installation
```bash
claude plugin marketplace add sandrocosta8902-jpg/curly-meme
claude plugin install schweizer-rechtsassistent@curly-meme
```

Dieses Repository enthält keinen Code des Plugins `code-review`; dieses stammt aus `claude-plugins-official`.
